# Кітапхана ақпараттық жүйесі

## Жоба туралы

Кітапхана ақпараттық жүйесі кітап қорын есепке алу,
оқырмандарды тіркеу, кітаптарды іздеу, онлайн брондау,
кітап беру және қайтару процестерін автоматтандыруға арналған.

## Жүйенің негізгі пайдаланушылары

- Оқырман
- Кітапханашы
- Әкімші
- Кітапхана басшысы

## Негізгі мүмкіндіктер

- Пайдаланушыны тіркеу
- Жүйеге кіру
- Кітаптарды іздеу
- Кітап туралы ақпаратты көру
- Кітапты онлайн брондау
- Кітаптың нақты санын көру
- Кітап беру және қайтаруды тіркеу
- Кітап қорын басқару
- Пайдаланушыларды басқару
- Есеп және статистика жүргізу

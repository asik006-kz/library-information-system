# Кітапхана ақпараттық жүйесі

## Жоба туралы

Кітапхана ақпараттық жүйесі кітап қорын есепке алу, оқырмандарды тіркеу, кітаптарды іздеу, онлайн брондау, кітап беру және қайтару процестерін автоматтандыруға арналған.

## Жүйенің негізгі пайдаланушылары

- Оқырман
- Кітапханашы
- Әкімші
- Кітапхана басшысы

## Негізгі мүмкіндіктер

- Пайдаланушыны тіркеу
- Жүйеге кіру
- Кітаптарды іздеу
- Кітап туралы ақпаратты көру
- Кітаптың нақты санын көру
- Кітапты онлайн брондау
- Кітап беру және қайтаруды тіркеу
- Кітап қорын басқару
- Пайдаланушыларды басқару
- Есеп және статистика жүргізу

## Кітап іздеу

Оқырман кітапты атауы, авторы және санаты бойынша іздей алады.

### Іздеу мүмкіндіктері

- Кітап атауы бойынша іздеу
- Автор бойынша іздеу
- Санат бойынша іздеу
- Қолжетімді кітаптарды көру

## Кітапты брондау

Оқырман жүйе арқылы қажетті кітапты онлайн брондай алады.

Брондау кезінде:

- Кітап таңдалады
- Брондау жасалады
- Брондау мерзімі белгіленеді
- Брондау статусы сақталады

## Кітап беру және қайтару

Кітапханашы жүйе арқылы кітап беру және қайтару операцияларын тіркейді.

Жүйеде:

- Берілген кітап туралы ақпарат
- Қайтару мерзімі
- Нақты қайтарылған күн
- Айыппұл сомасы

сақталады.

## Пайдаланушылар

Жүйеде бірнеше пайдаланушы рөлі қарастырылған:

### Оқырман

- Жүйеге кіру
- Тіркелу

- Кітап туралы ақпаратты көру

### Кітапханашы

- Жүйеге кіру
- Кітап іздеу
- Кітап беру
- Кітап қайтару
- Кітаптарды басқару
- Кітап қорын жаңарту

### Әкімші

- Жүйеге кіру
- Пайдаланушыларды басқару
- Жүйені басқару
- Есептерді қарау

### Кітапхана басшысы

- Жүйеге кіру

## Деректер қоры

Жүйеде SQL Server деректер қоры қолданылады.

### Негізгі кестелер

- `admins` — әкімшілер туралы ақпарат
- `readers` — оқырмандар туралы ақпарат
- `librarians` — кітапханашылар туралы ақпарат
- `catalogs` — кітап каталогтары
- `books` — кітаптар туралы ақпарат
- `reservations` — кітап брондаулары
- `loans` — кітап беру және қайтару операциялары

## Деректер қорының байланыстары

- `admins` → `readers`
- `admins` → `librarians`
- `librarians` → `catalogs`
- `catalogs` → `books`
- `readers` → `reservations`
- `books` → `reservations`
- `readers` → `loans`
- `librarians` → `loans`
- `books` → `loans`

## SQL операциялары

Деректер қорында негізгі SQL операциялары қолданылған:

- `CREATE TABLE` — кестелерді құру
- `INSERT` — мәлімет қосу
- `UPDATE` — мәлімет өзгерту
- `DELETE` — мәлімет жою
- `SELECT` — мәліметтерді шығару

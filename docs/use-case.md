# Use Case

## Актерлер

### Оқырман
- Жүйеге кіру
- Тіркелу
- Кітап іздеу
- Кітаптың нақты санын көру
- Кітапты онлайн брондау

### Кітапханашы
- Жүйеге кіру
- Кітап беру
- Кітап қайтару
- Кітап қорын басқару

### Әкімші
- Жүйеге кіру
- Пайдаланушыларды басқару
- Есептерді қарау

## Негізгі Use Case

- UC-01 — Жүйеге кіру
- UC-02 — Кітап іздеу
- UC-03 — Кітапты брондау

## UC-03: Кітапты брондау

1. Оқырман кітапты таңдайды.
2. «Брондау» батырмасын басады.
3. Жүйе сұранысты қабылдайды.
4. Жүйе кітапты броньдайды.
5. Жүйе пайдаланушыға хабарлама көрсетеді.

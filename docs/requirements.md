# Жүйе талаптары

## Функционалдық талаптар

| ID | Талап |
|---|---|
| FR-01 | Пайдаланушыны тіркеу |
| FR-02 | Логин және құпиясөз арқылы кіру |
| FR-03 | Кітапты атауы, авторы, санаты бойынша іздеу |
| FR-04 | Кітаптың негізгі ақпаратын көрсету |
| FR-05 | Қолжетімді кітапты онлайн броньдау |
| FR-06 | Кітаптың нақты қолжетімді санын көрсету |
| FR-07 | Кітапханашы кітапты қосу, өзгерту, өшіру |
| FR-08 | Кітаптың берілуін және қайтарылуын тіркеу |
| FR-09 | Әкімші пайдаланушыларды басқаруы |
| FR-10 | Кітап қоры мен қозғалысы бойынша есеп |

## Функционалдық емес талаптар

- Өнімділік
- Қауіпсіздік
- Қолдануға ыңғайлылық
- Тұрақты қолжетімділік
- Деректер сенімділігі
- Масштабталу
- Жауап беру жылдамдығы
- Деректердің өзектілігі
- Қалпына келтіру
- Үйлесімділік
